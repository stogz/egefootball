# Season logs

One file per season, written by the admin portal at the end of it: every game
with the stats posted in it and the booster that was riding on it, every credit
earned, and everything bought with them.

These are a record, not a source. Nothing on the site reads them to work
anything out — they are here so a season that has been cleared out of Supabase
is still on the record afterwards.

Empty until the first season has been played out and locked.
